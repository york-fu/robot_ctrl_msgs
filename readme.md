# robot_ctrl_msgs

robot_ctrl_msgs contains base messages, services useful for controlling robots.

msg provides representations for joint and cartesian trajectories and robots state.

srv provides general scalar and vector types.

## Message Definitions

- msg/JointState.msg
- msg/JointCmd.msg
- msg/Spatial.msg
- msg/SpatialArray.msg
- msg/SpatialStamped.msg
- msg/SpatialArrayStamped.msg
- msg/RobotCmd.msg
- msg/RobotState.msg
